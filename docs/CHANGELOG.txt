MDRG PANEL - chat with your bot (local Ollama) + a small cheat panel, in your web browser

NOTE: this game's build has Unity's built-in GUI (IMGUI) stripped out, so the plugin does not draw
anything itself. The in-game chat uses the game's own popup windows; the rest runs in a local web page.

REMOVE THE OLD PLUGINS FIRST
Delete ModMenu.dll and JunChat.dll from <game folder>\BepInEx\plugins\ (this replaces both).

BUILD
1. .NET 6 SDK (or newer) installed.
2. Check GameDir in MdrgPanel.csproj.
3. In this folder run:   dotnet build -c Release
4. Copy bin\Release\net6.0\MdrgPanel.dll into <game folder>\BepInEx\plugins\

USE
1. Make sure Ollama is running. Start the game and load a save.
2. IN GAME: press F2. The game's own input window opens ("Chat with <bot>"). Type, confirm,
   and your bot SAYS the reply with the game's own speech display (mouth animation included).
   Press F2 again to answer. If she is not on screen, or in a story scene, or something goes
   wrong, the reply appears in a game popup instead. (Key and style are in the config.)
3. BROWSER (optional): open http://127.0.0.1:8765 for the same chat plus a cheat panel for
   money, tokens and stats. It also has an "Open chat window in the game" button.
Settings (model name, personality, reply length, port) are in
<game folder>\BepInEx\config\local.mdrgpanel.cfg after the first run.
The model name must match 'ollama list' exactly.

If something does not work, open the Debug section on the page and send me what it says,
plus BepInEx\LogOutput.log.


WHAT THE IN-GAME CHAT DOES (v1.3)
- F2 opens the input window and zooms in on her (only on the interaction screen). F4 toggles the zoom by hand.
  If you were ALREADY zoomed in when you pressed F2, press F4 once to fix it.
- Her reply appears in the game's speech box next to her, with her name above it, and it does not fade.
  It stays for BubbleSeconds after she finishes (config, default 25; 0 = until you chat again).
- Her mouth moves while she talks (SpeakSpeed in the config).
- The model starts each reply with tags such as [happy] [sad] [angry] [shy] [surprised] (add "very") and
  sometimes a gesture: [wave] raises her right hand, [point], [lecture]. The plugin turns them into the game's
  own face and arm poses (Expression/*, ArmR/*) and hides the tags. Arms go back down after 3 seconds.
- The list of emotes the game has is on the web page under Debug and in LogOutput.log.
